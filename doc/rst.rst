reStructuredText
================

Documentation on reStructuredText can be found on the  
`Sphinx page <https://www.sphinx-doc.org/en/master/usage/restructuredtext/index.html>`_.

The html-theme used is `furo <https://sphinx-themes.org/sample-sites/furo/>`_.

The tool used to generate the html is `Esbonio <https://docs.esbon.io/en/latest/index.html>`_.
